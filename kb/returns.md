# Return & Refund Policy

## Standard Returns
- 30-day return window from delivery date
- Items must be unused and in original packaging
- Original receipt or order confirmation required
- Refund processed within 5-7 business days after we receive the item
- Refund goes back to original payment method

## Return Process
1. Contact customer support to initiate a return
2. You will receive a prepaid return shipping label via email
3. Pack the item securely with all accessories and original packaging
4. Drop off at any carrier location
5. Refund issued once item is received and inspected

## Return Shipping Costs
- Free return shipping for defective or incorrect items
- $5.99 restocking fee deducted from refund for change-of-mind returns
- Customer is responsible for return shipping if item was shipped internationally

## Non-Returnable Items
- Gift cards
- Software downloads / digital products
- Personal care items (earbuds, etc.) if seal is broken
- Items marked "final sale" on product page

## Damaged / Defective Items
- Report within 48 hours of delivery
- We will send a replacement or full refund including shipping
- No restocking fee for defective items

## Warranty Claims
- All products have a manufacturer warranty (varies by product)
- For warranty claims after 30 days, contact the manufacturer directly
- We can assist with the warranty claim process within the first year
